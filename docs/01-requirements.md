# seesee / 看看 — 需求分析

> 版本 v0.1 · 2026-11-06 · 目标平台 Windows 10/11 x64

## 1. 背景与问题

Windows 自带的「照片」应用和多数免费看图工具把"看图"这件小事做重了：

| 痛点 | 具体表现 | 影响 |
| --- | --- | --- |
| **慢** | 冷启动 1–3 秒，图片先糊后清（先上一张低分辨率占位图再慢慢补全） | 每次看一张图都要等，一天几十次 |
| **重** | 基于 Electron / UWP / .NET，安装包几十上百 MB，常驻进程和后台更新 | 占内存、占 CPU、拖慢机器 |
| **广告与推广** | 看图工具里塞广告位、资讯流、云盘推广、"猜你喜欢" | 干扰，且无法关闭 |
| **功能不对味** | 要么只有"看"（缺缩放/翻页/同目录浏览），要么堆满照片管理、修图、云相册 | 看图的路径变长 |

核心诉求一句话：**双击图片，画面立刻出现，然后用键盘就能把这一批图看完。**

## 2. 目标与非目标

### v1 目标（本版本范围）

1. **极速**：冷启动到首张图片上屏 < 150 ms（目标 80 ms 级），翻页 < 30 ms（命中预取时 < 5 ms）。
2. **键盘流**：左右翻页、翻到边界有明确反馈、100% / 适应窗口一键切换。
3. **同目录自动浏览**：打开一张图即自动加载同目录所有支持的图片，按自然序排列（`img2.jpg` 排在 `img10.jpg` 前）。
4. **格式覆盖**：JPEG / PNG / BMP / GIF / TIFF / ICO / WebP，并在系统装有对应解码器时支持 AVIF / HEIC / JXL / JXR。
5. **界面干净**：无广告、无资讯流、无账号；深色、无边框、控件按需出现（看图时几乎看不见 UI）。
6. **一键设为默认看图工具**：不改系统文件、不需要管理员权限。

### 明确的非目标（v1 不做）

- 照片管理（相册、标签、人脸、评分、搜索）——留给 v2。
- 图片编辑（裁剪、旋转保存、调色、批量重命名/转换）。
- 动图播放（GIF/WebP 动画）——v1 只取首帧，v2 做。
- 视频、RAW、PSD 等专业格式。
- 云同步、账号、遥测、自动更新。

## 3. 用户与使用场景

- **主力场景**：从资源管理器双击一张图 → 立刻看图 → 键盘/滚轮把同目录几十张翻完 → Esc 关闭。
- **次场景**：截图后快速核对（Ctrl+O 或拖放）；素材挑选（在文件夹里来回比对）。
- **用户画像**：Windows 桌面用户，习惯键盘，反感等待与广告；不要求修图功能。

## 4. 需求清单与优先级

### P0（v1 必须有）

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| R1 | 双击图片启动并显示 | 冷启动 → 首图上屏 ≤ 150 ms（本机实测 80–115 ms） |
| R2 | 同目录图片自动加载 | 打开即扫描目录，状态栏显示「第 N / 共 M 张」 |
| R3 | 键盘翻页 | ←→↑↓ / PgUp / PgDn / Home / End；到首尾有视觉反馈 |
| R4 | 适应窗口 / 100% | 双击、`0`、`1`、`+`、`-`、Ctrl+滚轮 |
| R5 | 缩放与平移 | 以光标为锚点缩放；放大后可拖动；边界自动回弹 |
| R6 | 邻图预取 | 当前图前后各预取 2–3 张，翻页不闪、不等待 |
| R7 | 格式支持 | 见第 5 节；不支持的格式给出明确提示而非白屏 |
| R8 | EXIF 方向 | 竖拍照片按 EXIF 方向摆正 |
| R9 | 深色 UI + 系统标题栏 | 标题栏交给系统（标题显示「看看 · 文件名 (i/n)」），自绘底部控制条 + 左下信息胶囊 + 底部胶片条 |
| R10 | 全屏 | F11 切换，Esc 退出全屏（再按 Esc 关窗） |
| R11 | 打开方式 | Ctrl+O 文件对话框；从资源管理器拖放 |
| R12 | 设为默认看图工具 | Ctrl+D 或 `--register`：写入 HKCU 关联 + 打开系统「默认应用」页；失败时自动生成 `.reg` 兜底 |
| R13 | 设置面板 | `Ctrl+,` 打开右侧抽屉，含「通用 / 快捷键 / 关于」三页；改动即时生效并持久化到 `settings.ini` |
| R14 | 多国语言 | 简体中文 / English / 跟随系统；切换即时生效、无需重启；新增语言只需补一张文案表 |
| R15 | 快捷键自定义 | 15 条命令全部可改键：点击键帽→按新键；冲突自动解绑并提示；`Delete` 解绑、`Esc` 取消、一键恢复默认；`Esc` 固定不可改 |

## 5. 格式与解码策略

| 格式 | 解码器 | 说明 |
| --- | --- | --- |
| JPEG (`.jpg .jpeg .jpe .jfif`) | WIC | **DCT 级缩放解码**（`IWICBitmapSourceTransform`），直接解出屏幕上需要的大小 |
| PNG / BMP / GIF / TIFF / ICO | WIC | 走格式转换 + Fant 缩放 |
| WebP / AVIF / HEIC / JXL / JXR | 系统扩展 | 系统装了对应 WIC 编解码器即可用，否则提示"无解码器" |

> 关键设计：**只解出需要的像素**。4K 屏上看一张 6400×4000 的 JPEG，屏幕上只需要约 3000×1900，DCT 缩放解码省掉一半以上的解码时间与内存。

## 6. 性能指标（本机实测，i5-12400F / RTX 4060 / 3840×2160）

| 场景 | 实测 |
| --- | --- |
| 冷启动 → 首图上屏（1920×1200 JPEG） | **80.6 / 81.7 / 84.2 ms** |
| 冷启动 → 首图上屏（6400×4000 JPEG，25.6 MP） | **106.2 / 114.9 ms** |
| 4K 窗口内平移/缩放每帧 | 14.7–15.9 ms（63–68 fps） |
| 单文件体积 | 703 KB（静态链接，无运行时依赖） |

分帧（1920×1200 样本）：exe 加载 9–14 ms → 建窗 4.6 ms → 建 D2D 软件设备 10 ms ‖ 解码 12–13 ms（并行）→ 首帧绘制 18–19 ms。

## 7. 关键约束

- 单文件、绿色：不写系统目录，不需要管理员权限，卸载 = 删除 exe。
- 隐私：不联网、无遥测、无自动更新。
- 目标系统：Windows 10 1809+ / Windows 11 x64（Per-Monitor V2 DPI、暗色标题栏）。
