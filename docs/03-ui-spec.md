# seesee / 看看 — UI 设计规范

> 版本 v0.1 · 2026-11-06 · 可执行参考：[`prototype/ui-mockup.html`](../prototype/ui-mockup.html)

## 1. 设计原则

1. **图是主角**：除标题栏与底部控制条外没有任何常驻装饰；看图时 UI 尽量"退场"。
2. **深色到底**：不用亮色面板，不做半透明白底卡片——所有浮层都是"深色玻璃"，靠 1px 描边和 4–8% 白色叠加区分层次。
3. **信息就在图上**：尺寸/格式/文件大小/页码贴在画布左下角，不占独立状态栏。
4. **控件按需出现**：鼠标静止 2.5 秒后控制条淡到 12% 不透明度，移动即回。
5. **只有一个强调色**：`#5B9CFF` 只用于"当前选中"和"可点击焦点"，不用于装饰。

> **标题栏归属（v0.2 起）**：顶部只有**一根**标题栏，由 Windows 自己绘制（`WS_OVERLAPPEDWINDOW` 系统边框，`DWMWA_USE_IMMERSIVE_DARK_MODE` 深色）。窗口标题由程序维护为 `看看 · <文件名>  (当前/总数)`，随翻页更新。客户区不再自绘标题栏与最小化/最大化/关闭按钮——缩放边框、拖动、双击最大化、贴边分屏、Snap Layouts 全部用系统行为。全屏时去掉 `WS_CAPTION | WS_THICKFRAME`，客户区铺满。

- 画布 = 窗口 − 标题栏高度；照片始终在画布内居中，`Fit` 模式下长边贴边（留 0 padding，交由缩放算法抗锯齿）。
- 底部 pill 浮在画布之上（不挤压画布），水平居中、距底 14。
- 左下信息胶囊与 pill 同基线，靠左 12。

## 4. 组件

### 4.1 标题栏

> v0.2 起 4.1 不再由程序自绘，改为系统标题栏：标题文本 = `看看 · <文件名>  (当前/总数)`，图标 = `resources/seesee.ico`，深色由 DWM 提供。原「自绘标题栏」的令牌（34 px、46 × 34 命中区、#E81123 关闭态）保留在原型里作为历史设计参考。

### 4.2 底部控制条（pill）

顺序：`‹` `›` ｜ `−` `+` ｜ 「适应」｜ 缩放百分比 ｜ 全屏图标。
- 每个图标按钮 32 × 32，圆角 6。
- 缩放百分比是**可点击按钮**（点击 = 回到 100%）；等宽字体。
- 整体：`surface` 底 + `border` 1px 描边 + 12 px 阴影，圆角 22。

### 4.3 信息胶囊

`6400 × 4000   JPG   13.0 MB   3/6`：像素尺寸 · 格式 · 文件体积 · 当前/总数。等宽字体，`text2` 色。

### 4.4 左右翻页箭头

半透明圆形按钮，`opacity 0`，仅在指针进入画布左右 15% 区域或悬停时淡入（原生版常驻可见，见 §7 差异）。

### 4.5 画布手势

- 拖动：指针为 `grab` / `grabbing`；仅放大状态可拖。
- 双击：`Fit` ↔ `100%`，以双击点为锚。
- 滚轮：翻页；`Ctrl+滚轮`：缩放（以指针为锚）。

## 6. 状态

| 状态 | 表现 |
| --- | --- |
| 加载中 | 画布底色 + 极小的居中细环（不进进度条，避免视觉噪音） |

## 8. 无障碍与细节

- 所有命中区域 ≥ 32 × 32；标题栏按钮 46 × 34。
- 不做纯色反转主题（深色是产品性格），但保证文字对比度 ≥ 4.5:1（`text` 对 `canvas` ≈ 13:1）。
- 高 DPI：`dpiScale_ = monitorScale × uiScale`，其中 `monitorScale` 由 `GetDpiForWindow` 取真实值（**启动时必须初始化**，否则 250% 屏上所有尺寸按 96 dpi 画出，字小一半）；`uiScale` 是用户偏好的额外倍率（0.75–3.0，存 `settings.ini` 的 `uiScalePct`）。Per-Monitor V2，显示器切换时重建后备缓冲。
- 动画：仅悬停/淡出，时长 120–180 ms，`ease-out`；不做位移动画（会打断看图）。

## 9. 胶片条（已实现）

| 项 | 值（逻辑像素，均乘 `dpiScale_`） |
| --- | --- |
| 条高 | 86 |
| 缩略图 | 60 × 60 方框，图按 contain 内接，解码长边 256 px |
| 间距 / 内边距 | 8 / 12 |
| 当前项 | accent 描边 2 px + 圆角 6 |
| 格底色 | `#232830` |
| 预取范围 | 当前索引 ±40（后台最低优先级解码） |

- 内容宽度 ≤ 视口时整排居中；超出时当前项居中，边界处不留白。
- 全屏或 `T` 隐藏时高度为 0，画布随之变高（`AreaRect` 动态扣减）。
- 胶片条**不参与**自动淡出：看图时缩略图常驻，底部 pill / 信息胶囊 / 箭头才会淡出。

## 10. 设置面板（已实现，v0.3）

右侧滑出抽屉，`Ctrl+,` 或底部 pill 的齿轮按钮开关；面板打开时底部控件**不淡出**，滚轮在面板内滚动列表而不是翻页。

| 项 | 值（逻辑像素，均乘 `dpiScale_`） |
| --- | --- |
| 宽度 | `min(380, 客户区宽 × 46%)` |
| 底色 / 分隔 | `#14171C` @0.985 + 左缘 1 px `#2A2F36` |
| 内边距 | 18 |
| 标题 | 15.5 px `text`，右端 24 × 24 关闭 ✕ |
| 标签页 | 三枚 pill，高 30，间距 4；槽底 `#0F1114` @0.9，选中 `#262B33` |
| 行高 | 34（开关行 / 快捷键行） |
| 开关 | 38 × 22，开 = `#5B9CFF` @0.85 + 白色圆钮，关 = `#2A2F36` |
| 键帽 | 高 24，宽 = 文本宽 + 20，底 `#24282F`；捕获态 accent 描边 |
| 滚动条 | 宽 3，`#FFFFFF` @0.16，仅内容溢出时出现 |

- **通用**：语言三选一（跟随系统 / 中文 / English）、界面缩放 `[−] 100% [+] [重置]`、开关（底部胶片条 / 控件自动隐藏 / 滚轮翻页 / 小图放大到窗口）、「设为默认看图工具」主按钮。
- **快捷键**：22 行「命令名 + 键帽」，点键帽进入捕获态（面板独占键盘，显示「请按新按键…」）；`Esc` 取消、`Delete`/`Backspace` 解绑；新键与其它命令冲突时自动解绑对方并用 toast（4 s）提示「该键已用于「上一张」」。页脚固定显示 `Esc`/`Delete` 提示与「恢复默认」，不随列表滚动。
- **关于**：`看看 · 版本`、一句话定位、技术栈、性能实测、仓库地址（accent 色）、MIT。
- 切换语言/开关即时生效并写 `settings.ini`，无需重启。

## 11. 多语言

- 全部界面字符串集中在 `src/i18n.cpp` 的 `kTable[]`（`{kStr, 中文, English}`，顺序必须与 `enum Str` 一致），业务代码只调 `i18n::T(i18n::kXxx)`，禁止内联硬编码文案。
- 「跟随系统」用 `GetUserDefaultUILanguage()` + `PRIMARYLANGID()==LANG_CHINESE` 判定；选择存 `settings.ini` 的 `language=0|1|2`。
- 中文优先用系统字体 `Microsoft YaHei UI`／`Segoe UI Variable Text`，英文同为该族（西文形），不混排。
- 新增语言只需在 `kTable[]` 里加一列（`enum` 加维度即可），目前支持 简体中文 / English 两种。

## 12. 右键菜单（v0.3.1）

- 触发：客户区右键 / `Shift+F10` / 菜单键（统一走 `WM_CONTEXTMENU`）。用系统原生 `TrackPopupMenu`（深色外观由系统跟随），不自绘，保证键盘导航与可访问性。
- id 约定：`id = keys::Cmd + 1`（菜单项与快捷键共用同一套命令）；另有两个专用 id：`900` = 打开设置、`901` = 退出。
- 分组与顺序：`上一张 / 下一张` ｜ `适应窗口 / 原始大小 / 放大 / 缩小 / 全屏` ｜ `复制图片 / 复制文件 / 剪切文件 / 复制路径` ｜ `在资源管理器中显示 / 用默认程序编辑 / 移到回收站` ｜ `设为默认看图工具 / 设置…` ｜ `退出`。
- 无图时所有依赖当前文件的项 `MF_GRAYED`。
- 实现要点：复制图片 = 全尺寸解码 → 反乘 alpha → `CF_DIBV5`（带 alpha mask）；复制 / 剪切文件 = `CF_HDROP` + `Preferred DropEffect`（剪切后到资源管理器粘贴即移动）；移到回收站 = `SHFileOperationW(FOF_ALLOWUNDO | FOF_WANTNUKEWARNING)`，确认交给系统，删完自动重扫目录并停在相邻位置。

## 13. 关联引导（不弹自家对话框，v0.3.1）

- 原则：`Ctrl+D`、面板主按钮、菜单项统一走 `App::RegisterAsDefault()`，**不再使用 `MessageBox`**。
- 成功：写 HKCU（ProgID + OpenWithProgids + Capabilities + RegisteredApplications）→ `SHChangeNotify` → 直接打开系统「默认应用」（`ms-settings:defaultapps?registeredAppUser=SeeSee`），toast「已注册，请在系统「默认应用」里确认」，并自动打开设置面板。
- 失败（注册表被安全软件拦截）：把生成的 `seesee-assoc.reg` 路径记入 `lastRegFile_`、`regBlocked_ = true`，打开设置面板→通用页，在「设为默认看图工具」下方追加：引导文案（`kRegBlockedHint`）+ 「导入关联文件」主按钮（`ShellExecuteW` 打开 .reg，合并确认是系统行为）+ 「打开系统设置」次按钮。
- 相关文案：`kRegBlockedHint` / `kImportRegFile` / `kOpenSystemSettings` / `kSetDefaultDone`。
