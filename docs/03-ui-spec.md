# seesee / 看看 — UI 设计规范

> 版本 v0.1 · 2026-11-06 · 可执行参考：[`prototype/ui-mockup.html`](../prototype/ui-mockup.html)

## 1. 设计原则

1. **图是主角**：除标题栏与底部控制条外没有任何常驻装饰；看图时 UI 尽量"退场"。
2. **深色到底**：不用亮色面板，不做半透明白底卡片——所有浮层都是"深色玻璃"，靠 1px 描边和 4–8% 白色叠加区分层次。
3. **信息就在图上**：尺寸/格式/文件大小/页码贴在画布左下角，不占独立状态栏。
4. **控件按需出现**：鼠标静止 2.5 秒后控制条淡到 12% 不透明度，移动即回。
5. **只有一个强调色**：`#5B9CFF` 只用于"当前选中"和"可点击焦点"，不用于装饰。

## 2. 设计令牌

### 颜色

| 用途 | 令牌 | 值 |
| --- | --- | --- |
| 画布底色 | `canvas` | `#0F1114` |
| 标题栏 | `titlebar` | `#16191E` |
| 浮层/控件底 | `surface` | `#1B1E23` |
| 分隔线 / 描边 | `border` | `#2A2F36` |
| 主文字 | `text` | `#E8EAED` |

| 弱文字 | `text3` | `#6B7480` |
| 强调色 | `accent` | `#5B9CFF` |
| 悬停叠加 | `hover` | `#FFFFFF` @ 8% |

## 3. 布局

```
┌───────────────────────────────────────────────────────────────┐
│ ⊙ 看看 · img102.jpg                              −   □   ×    │ 34px 标题栏
├───────────────────────────────────────────────────────────────┤
│                                                               │
│  ‹                                                      ›     │ 画布（照片居中、按窗口适配）
│                                                               │
│  ┌───────────────────────┐                                    │
│  │ 6400 × 4000  JPG  13.0 MB  3/6 │        ‹ ›  −  +  适应 43%  ⛶ │ 底部 pill
│  └───────────────────────┘                                    │
└───────────────────────────────────────────────────────────────┘
```

- 画布 = 窗口 − 标题栏高度；照片始终在画布内居中，`Fit` 模式下长边贴边（留 0 padding，交由缩放算法抗锯齿）。
- 底部 pill 浮在画布之上（不挤压画布），水平居中、距底 14。
- 左下信息胶囊与 pill 同基线，靠左 12。

## 4. 组件

### 4.1 标题栏

- 左：应用标记（圆环 + 瞳孔点）+ 「看看」+ `·` + 文件名（超长省略中段）。
- 右：最小化 / 最大化-还原 / 关闭，每个 46 × 34 命中区，悬停 `hover` 叠加，关闭键悬停用 `#E81123`。
- 整条可拖动（`HTCAPTION`），双击最大化。

### 4.2 底部控制条（pill）

顺序：`‹` `›` ｜ `−` `+` ｜ 「适应」｜ 缩放百分比 ｜ 全屏图标。
- 每个图标按钮 32 × 32，圆角 6。
- 缩放百分比是**可点击按钮**（点击 = 回到 100%）；等宽字体。
- 整体：`surface` 底 + `border` 1px 描边 + 12 px 阴影，圆角 22。

### 4.3 信息胶囊

`6400 × 4000   JPG   13.0 MB   3/6`：像素尺寸 · 格式 · 文件体积 · 当前/总数。等宽字体，`text2` 色。

### 4.4 左右翻页箭头

半透明圆形按钮，`opacity 0`，仅在指针进入画布左右 15% 区域或悬停时淡入（原生版常驻可见，见 §7 差异）。

### 4.5 画布手势

- 拖动：指针为 `grab` / `grabbing`；仅放大状态可拖。
- 双击：`Fit` ↔ `100%`，以双击点为锚。
- 滚轮：翻页；`Ctrl+滚轮`：缩放（以指针为锚）。

## 5. 键盘映射

| 键 | 行为 |
| --- | --- |
| `←` `↑` `PgUp` | 上一张 |
| `→` `↓` `PgDn` | 下一张 |
| `Home` / `End` | 第一张 / 最后一张 |
| `0` / `1` | 适应窗口 / 100% |
| `+` / `-` | 放大 / 缩小 |
| 双击 | 适应窗口 ↔ 100% |
| `F11` | 全屏切换 |
| `Esc` | 退出全屏；非全屏时关闭窗口 |
| `Ctrl+O` | 打开文件 |
| `Ctrl+D` | 设为默认看图工具 |

边界行为：首/末张时继续按同方向**不循环**，箭头变灰（`text3`），不弹提示、不抖动。

## 6. 状态

| 状态 | 表现 |
| --- | --- |
| 加载中 | 画布底色 + 极小的居中细环（不进进度条，避免视觉噪音） |
| 解码失败 / 无解码器 | 居中一行 `text2` 文案 + 文件名，保留翻页能力 |
| 空目录 | 「这个文件夹里没有图片」+ 快捷键提示 |
| 全屏 | 隐藏标题栏与窗口边框，pill 仍可用，指针静止 2.5 s 后淡到 12% |
| 放大溢出 | 边界回弹（clamp），不留大黑边 |

## 8. 无障碍与细节

- 所有命中区域 ≥ 32 × 32；标题栏按钮 46 × 34。
- 不做纯色反转主题（深色是产品性格），但保证文字对比度 ≥ 4.5:1（`text` 对 `canvas` ≈ 13:1）。
- 高 DPI：所有尺寸乘 `dpiScale_`，Per-Monitor V2，显示器切换时重建后备缓冲。
- 动画：仅悬停/淡出，时长 120–180 ms，`ease-out`；不做位移动画（会打断看图）。
